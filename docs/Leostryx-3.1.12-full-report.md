## 1. Запуск приложения: integrity check

**Симптом.** Приложение падало на старте:

```
runtime integrity check failed: hash mismatch for seed/AGENTS.md
(expected=c93c8342… actual=8dd3f990…)
```

**Причина.** `app/assets/runtime/manifest.json` (и его bypass-оверлей) содержал устаревшую
таблицу SHA-256: файл `seed/AGENTS.md` был отредактирован, а манифест не пересчитан.
Дополнительно устарел `overlaySha256` в `app/assets/env/manifest.json`.

**Что сделано.**
- Пересчитаны оба runtime-манифеста (33 записи), добавлен `bin/rish_shizuku.dex`,
  в bypass сохранён хеш пропатченного `liblanguage_server.so`.
- Добавлен `tools/gen_runtime_manifest.py`: пересчитывает манифест для варианта,
  умеет `--check`, идемпотентен, падает, если в таблице есть файл, которого нет на диске.
- `rebuild.py` вызывает генератор перед упаковкой каждого варианта и обновляет
  `overlaySha256`.

**Проверка.** В обоих APK — 0 расхождений по таблице; приложение запускается.

## 2. Клавиатура и поле ввода

**Симптом.** При тапе по полю ввода фокус «уезжал», клавиатура открывалась и закрывалась
несколько раз; иногда фокус уходил на навбар.

**Причина.** Наши же обработчики перехватывали `pointerdown` и пересоздавали кнопки рядом с
редактором; в strict-mode оставался мёртвый блок `guard = {…}` (ReferenceError).

**Что сделано.**
- `agy_ru.js`: в `attachSubagentButton()` добавлена проверка `composerEditorFocused()` —
  пока редактор в фокусе, кнопка не пересоздаётся; на `pointerdown` возвращён
  `e.preventDefault()`; повторная привязка по `focusout`.
- Удалён мёртвый `guard` в `removeChip()` и обработчик `visibilitychange`.
- `agy_shield.js`: аналогичная проверка `editorFocused()` в `ensureButton()` + перепланирование
  по `focusout`.

**Проверка.** Клавиатура открывается один раз, фокус не смещается.

## 3. Переключение провайдеров (ядро)

### 3.1. Чёрный экран и «Leostryx failed to start»

**Симптом.** После переключения ядра — чёрный экран или экран ошибки
`Uncaught SyntaxError: Unexpected token '<'`; иногда нужно было нажать дважды.

**Причина (по `logcat`).** Встроенный скрипт восстановления маршрута до загрузки скриптов
делал `history.replaceState` на глубокий путь вида
`/c/<uuid>/section/outside-of-project/tab/artifact?file=…`. После этого относительные URL
`./generated/…` резолвились от этого пути, ядро отдавало на неизвестный путь `index.html`
(SPA-fallback, `200 text/html`), и `<script>` падал с `Unexpected token '<'`:

```
err=[JS Error https://127.0.0.1:48155/c/generated/boot/custom-elements-guard.js?v=3.1.0]
    Uncaught SyntaxError: Unexpected token '<'
```

**Что сделано.** Перед `history.replaceState` вставляется `<base href="/">`, поэтому все
относительные скрипты грузятся от корня. Запись `__agyNavRestore` (TTL 300 с) очищается
`agy_ru.js` после того, как маршрут отрисован.

**Проверка.** В `logcat` больше нет ошибок загрузки скриптов, переключение работает с первого тапа.

### 3.2. Черновик и вложения уезжали в «Проекты»

**Причина.** Восстановление черновика/вложений не было привязано к маршруту и срабатывало на
любом экране, попадая в композер «Проектов».

**Что сделано.** Восстановление выполняется только при совпадении навигационного пути (или
`pathname === "/"`), запись `__agyNavRestore` удаляется только после успешной вставки.

### 3.3. Экран перезапуска вместо тостов

Тосты «переключаю провайдеров» заменены полноэкранным экраном (`agy_loading.js`):
карточка в стиле приложения, логотип активного пака, шаги, прогресс, советы, 6 вариантов
анимации (`pulse → orbit → rise → scan → rings → glow`), тема и акцент берутся из токенов.

Доработки по кадрам записи:

| Дефект | Причина | Исправление |
| --- | --- | --- |
| Логотип не появлялся, потом «хлопал» | асинхронный `fetch` за контурами | все 4 пака вшиты в `agy_loading.js` (`BRAND_SVGS`) — логотип в первом кадре |
| Вариант анимации менялся после reload | `nextVariant()` вызывался заново | вариант сохраняется в `__agyCoreRestart.variant` и переиспользуется |
| Логотип темнел в `orbit`/`glow` | `color: var(--agy-accent)` на `.agy-load__logo` | перекрашивается только свечение/орбиты, логотип остаётся `var(--fg)` |
| Зависание на «Г» | печатная машинка перепечатывала последний шаг по кругу | шаги останавливаются на последнем, статус ставится целиком; перед закрытием — «Готово» |
| Откат прогресса 100% → 92% | `complete()` показывал 100% до перезагрузки | две фазы: 0→60% до reload, 60→99% после, 100% только когда готов чат |
| Карточка «дышала» | динамическая высота плашки совета и строки статуса | фиксированные высоты: статус 22 px, совет 60 px, длинный статус обрезается |
| Скачок контраста между фазами | вторая фаза стартовала на фолбэках, токены приезжали позже | цвета снимаются с живой темы и запоминаются (`__agyLoadTheme`), вторая фаза использует ровно их |
| Сплэш вылезал при переключении | `watchCore()` вызывал `showLoading()` на каждую генерацию | сплэш показывается только при запуске приложения |

### 3.4. Нативный сплэш (холодный старт)

- Раньше показывал гексагон-заглушку — заменён на **mono-логотип активного пака** с кольцами
  и тремя точками.
- Логотип рисовался чёрным на почти чёрном фоне: WebView применял **алгоритмическое
  затемнение**, потому что страница не объявляла поддержку тёмной темы. Добавлены
  `<meta name="color-scheme" content="dark light">` и `color-scheme: light dark`, цвета
  продублированы инлайном в `<body style="background:…; color:…">`.
- Падение приложения при переключении: `SplashController.setVisible()` вызывал
  `ViewPropertyAnimator.cancel()` как метод, возвращающий объект, — `NoSuchMethodError`
  и вылет на рабочий стол. Исправлено на `cancel()V`.
- `showLoading()` больше не зависит от `mode`: HTML перезаливается на каждый показ, поэтому
  содержимое не может «потеряться» после анимации скрытия.

### 3.5. Адаптивный сплэш под бренд

- `loadDataWithBaseURL(null, …)` → `loadDataWithBaseURL("https://127.0.0.1:48155/", …)`:
  страница получает origin приложения и видит тот же `localStorage`, что и интерфейс.
- В разметку вшиты все четыре логотипа со своими `viewBox`
  (Сова 1026×879, Рысь 760×765, Волк 1022×545, Медведь 852×672; прежние LSX/Угловой X
  полностью заменены — см. §12.1) — широкий Волк больше не
  задевает орбиты, слот ограничен 118×118.
- Синхронный скрипт в `<head>` читает `localStorage["agyBrandConfig"]` и до первой отрисовки
  выбирает пак логотипа и акцентный цвет; кольца, точки и логотип красятся акцентом (флаг
  `recolorLogo` учитывается экраном перезапуска, где логотип при `false` остаётся светлым).
- Дефолты сборки берутся из `app/assets/web/brand/config.json` — на чистой установке сплэш
  сразу показывает логотип и цвет сборки.

## 5. Видео: вложения и плеер

**Вложение.** Android WebView не генерирует миниатюру для локального видео, а в бандле для
категории `video` нет ни цвета, ни иконки — чип оставался пустым серым прямоугольником или
показывал битую картинку. `agy_media.js` заменяет превью аккуратным бейджем (иконка камеры +
`MP4`/`MOV`), проверяет чипы раз в секунду и возвращает бейдж после перерисовок React.

**Плеер.** `agy_player.js`:
- пока файл готовится — «Загрузка видео…» вместо чёрного экрана с `0:00 / 0:00`;
- своя нижняя панель, которая **не скрывается**: play/pause, −5 с, +5 с, таймкод (кнопки 44×44);
- тап по экрану больше не ставит паузу (клик гасится до обработчиков бандла);
- двойной тап по половинам — ∓5 с с всплывающим бейджем;
- включается звук (снимается `muted`) и выключается лупа `loop`.

**Ограничение.** Подготовка файла всё ещё идёт через base64-мост бандла (`readFile` →
base64 → Blob), поэтому первые секунды показывается спиннер. Чтобы убрать саму задержку,
нужна правка пути в минифицированном `main.js` (подстановка `URL.createObjectURL(file)`) —
вынесено в отдельный заход.

### 12.2. Коммутация ядра: полный маршрут восстановления

- **Приложение уходило на экран проектов.** Интерфейс отдаёт само ядро
  (`https://127.0.0.1:48155/`), а `watchCore()` после `restartCore()` делает полный
  `loadDataWithBaseURL` — роутер (TanStack) стартует на корне `/`. Восстановитель маршрута
  в `agy_ru.js` грузится с `defer` и опаздывал. Теперь восстановление маршрута встроено в
  `index.html` (инлайн, до бандла) — маршрут возвращается до инициализации роутера.
- **Черновик: переносы строк.** Lexical-редактор читался через `textContent` и терял `\n`.
  Чтение переведено на `innerText`, обратная вставка эмулирует
  `ClipboardEvent("paste")` через `DataTransfer` — структура абзацев сохраняется.
- **Черновик: надёжность.** Срок хранения поднят с 60 до 180 с; вставка проверяет
  результат и повторяется, если приложение затёрло окно ввода во время подъёма сессии.
- **Вложения через IndexedDB (`agyComposerRestore`).** `File`-объекты не переживают
  reload в принципе: выбранные файлы сразу складываются в IndexedDB, после возврата ядра
  `agy_ru.js` возвращает их в штатный `<input type="file">`, и приложение загружает их как
  обычные вложения. Копия удаляется после отправки/удаления, чтобы не тащить мусор.
- **Дублирование текста.** Строгая проверка содержимого редактора перед вставкой (если
  текст уже есть — повтор отменяется); таймер очистки `watchConsumed()` блокируется на
  время рестарта.

### 12.3. Меню и композер

- Метки «Ядро: Сторонние провайдеры (нажмите для…)» растягивали меню трёх точек —
  `__agyProviderTooltip()` теперь возвращает короткие «Пользовательские» / «Google Gemini».
- Имя модели вида `deepseek/deepseek-v4.1-flash-1017` растягивало кнопку выбора модели и
  скрывало кнопку субагентов — `[data-testid="model-selector-trigger"] > span:first-child
  { max-width: 130px }` с обрезкой `…`.
- Иконка `dns` (её нет в бандленном наборе Material Symbols — компонент выводил имя
  текстом, было «dns Провайдеры») заменена на `hub`, подпись — «Пользовательские».
- Иконка `hub` у строки переключения выглядела как пятилистник — заменена на `tune`
  (ползунки), в одном ряду с `edit`/`download`/`keep`/`archive`.
- **Кнопка субагентов не появлялась вовсе (регрессия 3.1.9):** в 3.1.9 четвёртый блок
  `agy_ru.js` перевели на локализатор `T(...)`, но `T` определён только в первом блоке —
  `ReferenceError: T is not defined` убивал весь блок: `attachSubagentButton()`,
  `MutationObserver`, удержание фона и восстановление черновика. Исправлено.

### 12.4. Видео: мгновенный старт

- **Причина 7-секундной задержки:** модальный плеер сериализовал файл в base64 data-URL
  через JSON-RPC-мост. В `generated/main.js` кодирование заменено на
  `URL.createObjectURL(new Blob([Y.content], { type: ea }))` — старт < 50 мс.
- `agy_player.js`: двойной тап по половинам — ∓5 с с бейджем; постоянная нижняя панель
  (play/pause, −5/+5, таймкод, хитбоксы 44×44); тап по экрану не ставит паузу; звук
  включён, лупа выключена.
- **Квадратные вложения:** фото были аккуратными квадратами 96×96, а видео и документы —
  сплюснутыми прямоугольниками 56 px. Для `[data-testid="input-attachment"]` зафиксированы
  `width: 96px; height: 96px; aspect-ratio: 1/1`.
- **Бейдж видео:** битый blob (`naturalWidth === 0`) скрывается через CSS, вместо него
  бейдж `.agy-media-badge` (камера + `MP4`/`MOV`); `MutationObserver` возвращает бейдж
  после перерисовок React.

### 12.5. Брендинг в нативе: `BrandHelper`

- **Новый класс `com.agy.brand.BrandHelper`** читает активный пак/цвет/`recolorLogo` из
  `web/brand/config.json` (в т.ч. из распакованного
  `/data/user/0/com.agyru.t2/files/web/brand/`), валидирует пак и отдаёт ресурсы.
- **Иконка уведомлений в статус-баре** адаптируется под бренд: `ForegroundNotification`/
  `AgyShade`/`NotificationHandler` берут `web/brand/<pack>/ic_notification.png`
  (масштаб с билинейной фильтрацией до 96×96 через `Icon`), вместо статического
  `ic_notification` — Совы.
- **Динамический сплэш:** раньше всегда рисовалась Рысь — JS-словарь `SVGS` ломался на
  двойных кавычках атрибутов SVG. Разделители исправлены на одинарные; сплэш читает пак,
  акцент и `recolorLogo` прямо из `config.json` (нативно) и рисует выбранный логотип.
  `loadDataWithBaseURL` получает `https://127.0.0.1:48155/` — доступ к общему `localStorage`.
- **Логотип на сплэше:** парсинг `ns0:path` в WebView чинился заменой префиксов на чистые
  теги и корректной сборкой `<svg>` — центральный логотип появился у всех паков.
- **Контраст:** `ThemeController` выровнен с фоном экрана загрузки (`-0xf4f1ef`), единой
  палитрой для сплэша и терминального экрана.
- **Просачивание акцента при `recolorLogo: false`:** `active_accent()` возвращает
  `var(--fg)` вместо цвета палитры; `applyAccent()` в `agy_loading.js` — ошибка
  `(themeAccent || color)` исправлена, логотип отображает оригинальные цвета.

### 12.6. Поле выбора оттенка

Попап выбора цвета темы в «Настройки › Оформление» был пустым и полупрозрачным: дочерние
слои градиента использовали синтаксис Tailwind v4 `--tw-gradient-stops: var(...)` с 4
аргументами, который Chromium отбрасывает, а глобальное правило карточек в `agy_ru.css`
затирало фон попапа. Синтаксис упрощён, фон зафиксирован — окно стало плотным, с 2D-градиентом.

### 12.7. Кликабельные пути: гарантированное открытие

- «Открыть папку»: устранён `SecurityException` из-за `FLAG_GRANT_READ_URI_PERMISSION` на
  чужом URI externalstorage — флаг заменён на `0x10000000` (`FLAG_ACTIVITY_NEW_TASK`),
  запуск через `am start` прямо в нужный каталог DocumentsUI.
- «Установить APK»: Intent снабжён `ClipData` и корректным MIME, системный установщик
  открывается с файла в чате.
- Тап ловится и по `click`, и по `pointerup` (приложение гасит click на pointerdown),
  zero-width-символы вычищаются, в `logcat` пишется диагностика `[agy_paths]`.
- В `seed/AGENTS.md` добавлен раздел **4.1**: правила вывода нажимаемых путей для агента —
  полный абсолютный путь отдельной строкой, без markdown-ссылок, под
  `/storage/emulated/0/`, проверка `ls -l` перед отправкой.

### 12.8. Падение на старте: `NoSuchMethodError: active_accent`

Промежуточный dex ссылался на хелперы `active_accent()/active_logo_color()/active_vb()/
active_in()`, но сами методы не были вшиты — приложение падало при **каждом** запуске в
`SplashController.loadInitial → SplashLoadingHtml.getLoadingHtml`. Методы добавлены:
выбирают `viewBox`/контуры активного пака, акцент и цвет логотипа из `BrandHelper`.
Все `invoke-static` по классу сверены — пропусков нет; проверено холодным стартом:
процесс жив, новых `FATAL` в `logcat` нет, сплэш рисует логотип выбранного пака.
