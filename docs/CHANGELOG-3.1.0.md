# Leostryx 3.1.0 — Changelog относительно апстрима v2.4.1

**База сравнения:** [werdio325-png/antigravity-android v2.4.1](https://github.com/werdio325-png/antigravity-android/releases/tag/v2.4.1)
**Текущая версия форка:** Leostryx 3.1.0 (versionCode 26)

Leostryx — русский форк Antigravity for Android с полностью переработанным интерфейсом, собственной линейкой релизов 3.0.x → 3.1.0 и рядом фич, отсутствующих в апстриме. Ниже — все отличия, сгруппированные по блокам.

---

## 1. 🌐 Локализация и брендинг
- **Полностью русский интерфейс** (assets/web: `agy_ru.css`, `agy_ru.js`, переводы инструментов, бэкапа, консоли и т.д.) — апстрим англоязычен.
- **Ребрендинг в Leostryx**: переименованы UI-строки, лейблы, описания; брендинг «lynx/Leostryx» (3.0.5, 3.0.6).
- **Живой SVG-акцент**: акцентный цвет применяется на лету ко всем элементам, включая иконку и сплеш (3.0.5, 8c0813b).
- **Динамические иконки лаунчера** (3.0.5) + **динамический сплеш-скрин Android 12+** через активный activity-alias, без статического animatedIcon (92e4497).
- **Тонировка сплеш-скрина в акцентный цвет**, убрано лишее уведомление о прогрессе агента (8c0813b).

## 2. 🎨 Темы и внешний вид
- **Стеклянные (glass) поповеры и карточки провайдеров**: полупрозрачные меню, попапы и карточки (3.0.7, c1f2988, 6a45a7b).
- **Правильная прозрачность по темам**: в тёмной теме — чёткая чистая прозрачность без blur; в светлой — стекло с повышенной прозрачностью (5b11fa0, 7677db4).
- **Плоское стекло 88%/72% без акцентного оттенка** — акцентная тема лишь слегка просвечивает, без серого затемнения (d88fac8).
- **Фикс полосы справа при скролл-локе** и задержки прикрепления меню (d94dd07).
- **Выбор шрифта в интерфейсе** — встроенный селектор с открытыми шрифтами, кнопка и дропдаун выровнены по блоку превью (4053454, 3c46957).
- **Переключатель акцентного цвета** в настройках (3.0.8).

## 3. 📎 Файловый пикер и вложения
- **Убран чёрный экран и лаг при открытии пикера**: удалён `overridePendingTransition`, упрощены MIME-типы (5179f6f).
- **Убрана задержка и зависание при прикреплении файлов** (ef2aa78).
- **Пикер открывается на «Недавние»**: убрано принудительное перенаправление `INITIAL_URI images_root` в `MainActivity.smali` — выбор папки остаётся на пользователе, путь не навязывается.
- **Медиа-меню без задержки/сдвига**, без перехвата кликов по медиа (d88fac8, 3c46957).

## 4. 🧩 Новые функции (отсутствуют в апстриме)
- **In-app обновлятор с авто-установкой APK** — обновление прямо из приложения (3.0.8).
- **Backup & Restore**: вкладка бэкапа/восстановления, **базовый бэкап с уведомлением** (9b08819, c330146).
- **Консоль приложения + история ошибок с фильтром, экспорт в PDF, скроллбары** (3.0.1, 6aebe3c).
- **Селектор моделей (bottom-sheet)** и кнопка композера субагентов (3.0.8, 0c6d98c, c330146).
- **Субагенты** — поддержка мультиагентной работы (3.0.6).
- **Уведомления с ответом из шторки (shade reply)** (3.0.6).
- **Каталог архивов инструментов** и sdkmanager 37 canary (0c6d98c).
- **Терминальный спиннер** — фикс вращающегося индикатора в терминале (ef2aa78).

## 5. ⚙️ Среда выполнения и тулчейн
- **Bypass-вариант сборки** рядом с standard (региональный обход, интегрирован в runtime, 0c6d98c).
- **Оптимизации памяти runtime** (3.0.6).
- **Патч ELF-путей**: убраны захардкоженные пути Termux в `agy-fix-paths`, `runtime/bin` первый в PATH bash (2cc54a5).
- **openssl и JVM окружение** в bash, фиксы синтаксиса вкладок Backup/About/Feedback (b1d6044).
- **Фикс background stream** — стрим ответов не умирает при уходе в фон (3.0.5).
- **Фикс argon** (3.0.6).
- Апстримовские фичи, которые тоже есть здесь (унаследованы/поддержаны): web-терминал + PTY, `liblse_compat.so` для ARMv8.0-A, `agy-daemon`, torch-бридж.

## 6. 🔒 Безопасность
- **Ключи подписи удалены из репозитория** (d37a11f) — подпись только локальным keystore.
- **Убран `android:debuggable`** из production-сборок (как в апстриме #6, сохранено и усилено).
- **Дисклеймер Claude** с возможностью скрыть (0c6d98c).

## 7. 🔨 Сборка и релиз-инфраструктура
- **Автоматизация сборки**: `rebuild.py` — именование релизов 3.1.0, обновление mtime, синк project root, два варианта (standard/bypass) (01bc695, 2fd09fd).
- **Корректная версия при обновлении**: versionName 3.1.0 / versionCode 26 в манифесте — апдейт ставится поверх 3.0.x без даунгрейда номера.
- **Документация**: `docs/smali.md`, `docs/flutter-toolchain.md`, `docs/jadx-fixes.md` — фикс инструментальных путей JVM/Flutter/jadx под песочницу Android.
- **Чистое дерево**: без временных артефактов сборки.

## Итог
Форк Leostryx — это не «пачка патчей», а самостоятельная ветка: русификация + стеклянный UI с корректной темизацией, свои фичи (обновлятор, бэкапы, субагенты, селектор моделей/шрифтов, bypass-вариант), исправления пикера/вложений/терминала и автоматизированная двухвариантная сборка — всё, чего нет в апстриме v2.4.1.
