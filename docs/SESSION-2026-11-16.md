## 1. Запуск: runtime integrity check

**Симптом.** `core start failed: runtime integrity check failed: hash mismatch for
seed/AGENTS.md (expected=c93c83… actual=8dd3f9…)`, приложение не стартовало.

**Причина.** `assets/runtime/manifest.json` — таблица sha256, по которой Java-ядро перед
стартом сверяет файлы в `files/runtime`, — осталась от 22 октября. `seed/AGENTS.md`
переписали 15 ноября (блоки `AGY-LANG` и `AGY-BUILD-VERSION`), а хеш в таблице не
пересчитали. Дополнительно в таблице отсутствовал `bin/rish_shizuku.dex`, а в
`assets/env/manifest.json` был устаревший `overlaySha256` (из-за него устройство не
перекопировало бы обновлённый `etc/antigravity/AGENTS.md` в `$PREFIX`).

**Что сделано.**
- новый генератор `tools/gen_runtime_manifest.py`: пересчитывает таблицу по реальным
  файлам (для bypass учитывает пропатченный `bin/liblanguage_server.so`), умеет
  `--check`, идемпотентен (если ничего не изменилось — файл не трогает, сборка
  остаётся воспроизводимой);
- `rebuild.py` перед упаковкой каждого варианта вызывает генератор, а также
  пересчитывает `overlaySha256` через `tools/gen_env_overlay_sha.py` — правка любого
  файла runtime больше не может оставить таблицу устаревшей;
- таблица и `overlaySha256` пересчитаны, в неё добавлен `bin/rish_shizuku.dex`.

**Проверка.** Для обоих APK: 33 записи, расхождений с файлами внутри APK — 0.

## 2. Клавиатура: фокус уходил из поля ввода

**Симптом.** Тап по полю ввода — клавиатура открывается и закрывается несколько раз.

**Причина.** Регрессия коммита `c08b10e`: он убрал из `attachSubagentButton()` (и
`agy_shield.js`) предохранитель «не вставлять кнопку в футер, пока редактор в фокусе»,
который был добавлен в `daf0acb` с прямым комментарием *«skip DOM insertion while
editor is focused to avoid keyboard dismiss on Android»*, а вместе с ним — `preventDefault`
на `pointerdown` кнопки. Кнопки вставляются в футер окна ввода, а это React-контейнер:
вставка чужого узла по таймеру 400 мс и на каждую мутацию DOM заставляла React
пересобирать строку ввода, `contenteditable` пересоздавался, фокус терялся, Android
закрывал клавиатуру — и цикл повторялся.

**Что сделано.**
- в `agy_ru.js` и `agy_shield.js` вернули предохранитель (`composerEditorFocused()` /
  `editorFocused()`): пока редактор в фокусе, футер не трогаем;
- кнопки возвращаются сразу по `focusout`, а не в момент ввода;
- восстановлен `e.preventDefault()` на `pointerdown` кнопки субагентов;
- убраны `guard = {…}` в `removeChip()` и в обработчике `visibilitychange` — переменная
  нигде не объявлена, в `"use strict"` это `ReferenceError`, из-за которого не работало
  удаление чипа-упоминания и обработчик возврата в приложение.

## 3. Переключение ядра: чёрный экран и «failed to start»

### 3.1. Как искали

Первый заход был неверным (гонка распаковки web-бандла). Реальную причину дал `logcat`:
через Shizuku удалось снять `AGY_JS`, а наши же диагностические сообщения вывели строку

```
BOOT_DIAG ui=blank rs=complete root=yes
  url=127_0_0_1_48155_c_<uuid>/section/outside-of-project/tab/artifact?file=…
  err=[JS Error https://127.0.0.1:48155/c/generated/boot/custom-elements-guard.js?v=3.1.0]
      Uncaught SyntaxError: Unexpected token '<'
```

### 3.2. Настоящая причина

Инлайн-скрипт возврата маршрута в `index.html` перед монтированием роутера делает
`history.replaceState` на сохранённый путь. Если путь глубокий
(`/c/<uuid>/section/outside-of-project/tab/artifact?file=…`), то после подмены URL все
**относительные** `./generated/…` начинают резолвиться от этого пути
(`/c/generated/…`). Ядро на неизвестный путь отдаёт не 404, а `200 text/html` с
`index.html`, поэтому падали **все** скрипты страницы и оставался пустой (чёрный) экран.

Дополнительный эффект: запись `__agyNavRestore` живёт 5 минут, поэтому при каждом
перезапуске приложения экран снова был чёрным, пока запись не истечёт.

### 3.3. Что сделано

- `<base href="/">` добавляется в `<head>` **до** `replaceState` (и в `index.html`, и в
  `agy_ru.js` как страховка) — относительные ресурсы всегда грузятся с корня ядра;
- запись маршрута больше не удаляется на первой загрузке: живёт 5 минут и снимается,
  когда нужный маршрут реально отрисован;
- черновик и вложения восстанавливаются только на «своём» маршруте (на «Проектах» —
  никогда) и снимаются после успешной вставки;
- `startup_ready.js`: при startup-ошибке страница сама перезагружается (до 3 попыток при
  рестарте ядра, до 2 — в остальных случаях), а не показывает сразу фатальный экран;
- `BOOT_DIAG` — диагностика на экране ошибки в виде, который редактор натива не вырезает
  (URL без точек и слэшей, первый неудавшийся ресурс, первая ошибка);
- ошибки загрузки `<script>`/`<link>` теперь тоже перехватываются (capture-фаза).

**Проверка.** После установки переключение отработало штатно; в `logcat` больше нет
`Unexpected token '<'`.

## 4. Экран перезапуска ядра (новая функция)

Вместо тостов «Ядро перезапускается…» — полноэкранный экран в стилистике приложения.

- модуль `app/assets/web/agy_loading.js`, API `window.__agyLoading.show/hide/isActive`;
- содержимое: сканлайны, свечение, анимированное «ядро» (гексагон + два вращающихся
  кольца + пульс), печатающийся статус (останавливаю ядро → перечитываю конфигурацию →
  поднимаю службу → проверяю 127.0.0.1:48155 → возвращаю чат), прогресс с процентом,
  строка цели («Переключаю на ваши модели» / «…на встроенные модели Google Gemini»),
  ротация советов, `prefers-reduced-motion`, страховка от залипания 25 с;
- `applyRestart()` в `agy_providers.js` сначала показывает экран, через 360 мс
  останавливает ядро; после перезагрузки WebView экран возвращается с «Возвращаю чат»
  и плавно уходит, когда отрисовано поле ввода;
- оформление на токенах темы (`--background`, `--foreground`, `--primary`, `--card`,
  `--border`, `--muted-foreground`, `--font-family`), поэтому светлая, тёмная и
  кастомная темы подхватываются автоматически. Фон экрана = `var(--background)` — тот же
  цвет, что у нативного сплэша;
- **уход по реальной готовности UI.** Экран больше не снимается по факту появления поля ввода в DOM: `startup_ready.js` вместе с нативным сигналом выставляет `window.__agyUiReady` и бросает событие `agy-ui-ready` (с причиной — `messages-rendered`, `chat-input-ready` и т.д.), а экран уходит по нему, с паузой ~360 мс и двумя кадрами на отрисовку. Это убрало пустой (чёрный) кадр в конце переключения;
- **логотип вместо гексагона.** Экран читает `brand/config.json`, берёт активный пакет брендинга
  (`01_owl`, `02_lynx`, `03_lsx`, `04_angular_x`) и вставляет его mono-SVG. Mono-версия нарисована
  через `fill="currentColor"`, поэтому красится токенами темы: часть вариантов — цветом текста,
  часть — выбранным акцентом (`--primary`); работает и на светлой, и на тёмной, и на кастомной теме;
- **шесть вариантов анимации**, по кругу на каждый перезапуск: `pulse` (дыхание + свечение),
  `orbit` (вращающиеся пунктирные кольца), `rise` (подъём с растворением), `scan` (световая полоса
  по логотипу), `rings` (расходящиеся кольца), `glow` (пульсирующее свечение в акценте). Пока лого
  грузится — гексагон-заглушка, чтобы не было пустого кадра;
- **нативный сплэш** (`SplashLoadingHtml`) теперь показывает **тот же логотип**: mono-SVG
  активного пакета брендинга вшит прямо в HTML сплэша (в цветах темы, через
  `fill="currentColor"`), вокруг два вращающихся кольца, ниже три точки загрузки,
  `prefers-reduced-motion` учитывается. Раньше на холодном старте был виден гексагон, и
  запуск выглядел иначе, чем экран перезапуска. WebView сплэша больше не прозрачный — фон
  берётся из темы через `Color.parseColor(background())` с fallback, поэтому «чёрной» паузы
  между перезагрузками нет.

## 5. Кликабельные пути: папка и установка APK (новая функция)

- модуль `app/assets/web/agy_paths.js`;
- тап по пути `/sdcard/…`, `/storage/…`, `/data/…`, `/root/…`, `/mnt/…`, `/system/…`
  (в тексте или в `code`) открывает карточку с путём и действиями:
  **«Открыть папку»**, **«Установить APK»** (только для `.apk`), **«Копировать»**;
- React-DOM не трогается: путь определяется по координате тапа через
  `caretRangeFromPoint`/`caretPositionFromPoint`, поэтому узлы не оборачиваются и не
  перерисовываются;
- новый нативный мост `AgyTools.openPath(String)` (`@JavascriptInterface`): поднимается
  к существующему каталогу и открывает DocumentsUI сразу в нём
  (`content://com.android.externalstorage.documents/document/primary%3A…`, тип
  `vnd.android.document/directory`);
- установка использует уже существующий `AgyTools.installApk(String)`;
- системный Back закрывает карточку первым (`window.__agyBack`);
- оформление карточки — на тех же токенах темы, что и экран загрузки.

## Приложение Б. Хронология

1. Диагностика запуска → фикс runtime-манифеста → пересборка.
2. Жалоба на клавиатуру → найден регресс предохранителя → фикс.
3. Жалоба на переключение ядра → гипотезы → `logcat` → настоящая причина
   (относительные пути) → `<base href>` → проверка.
4. Просьба заменить тосты экраном загрузки → `agy_loading.js`.
5. Просьба сделать пути кликабельными → `agy_paths.js` + нативный `openPath`.
6. Просьба адаптировать под темы + убрать «чёрную вспышку» → токены темы,
   фон = `var(--background)`, патч HTML сплэша.
